## A. 背景纯色化

`body` 现在只有 `background: var(--bg)`，即 `--animal-bg` `#f8f8f0`。删掉的规则如下：

| 删除项 | 原内容 |
|---|---|
| 页顶六色糖条 | `background-image` 第 1 层 `linear-gradient(90deg, #19c8b9 … #e59266 83.3%)` |
| 波点 | `background-image` 第 2 层 `radial-gradient(circle, #efe9d6 2.5px, rgba(239,233,214,0) 3px)` |
| 两层配套声明 | `background-size: 100% 6px, 26px 26px;`、`background-repeat: no-repeat, repeat;`、`background-position: 0 0, 0 0;` |
| 注释 | body 内「v4 装饰只在页边…」一行；文件头【九】「装饰」一条已在【十】中注明作废（【九】原文作为历史保留） |

孤儿 CSS 变量：糖条和波点的颜色原本写的是字面值，没有引用变量，所以背景这项没有产生孤儿变量。

- `--on-accent: #2f2112`（原播放键字色）
- `--accent-active: var(--animal-primary-active)`（原播放中底色）

`--animal-primary-active` 这个令牌保留在 animal 令牌表里，与出处映射一致，只是现在没有页面变量引用它。

卡片、全文、选文面板的底色仍是纯色 `#f7f3df`，未改。

## B. 控件文字对比

### 配色方案

我选了两条路一起用，按控件性质分：

- **实底键**（假名/译「开」、☰ 选文、× 返回、播放键）
  - 底改为深青 `#085049`，字改为纯白 `#ffffff`。
  - 悬停 / 播放中换更深的 `#063c37`。
  - 原先薄荷底配深棕字、浅薄荷底配青字，两组颜色明度接近，所以看着发闷。现在是深底白字，反差明显。
- **浅底控件**（开关「关」、下拉、列表项）
  - 底不变，字改为最深棕 `#3b2a17`；副行改为 `#54402b`。
  - 开关「关」的描边加深到 `#a89878`。「开」是深青实底，「关」是浅底深字，一眼能分。
- **横屏页头键焦点态**：底会变成浅黄 `#fff0b8`，白字在上面会看不见，所以焦点态字色强制为 `#3b2a17`。
- **次要文字**加深：`--muted` `#6b5640`→`#54402b`，`--title` `#794f27`→`#6e4520`，`--err` `#a8382f`→`#8a2e26`。
- **ruby** 是正文类，新设变量 `--rt-ink` 并保持原值 `#6b5640`，不受 `--muted` 加深影响。
- **播放键加载中**：去掉 `opacity: .8`。合成后白字只有 5.5:1，低于 7。加载中仍有光标变化，键上也有「⏳ 准备中…」字样。
- **额外加了一项** `:root { color-scheme: only light; }`：
  - 用途：如果用户的浏览器开着「自动深色网页」，浅底按钮会被反成深底，这句可以阻止反色。
  - 无法确认这就是「深色按钮」反馈的成因：截图里的按钮本来就是浅底或薄荷底。
  - 不支持该关键字的内核会直接忽略，不影响正常渲染。
