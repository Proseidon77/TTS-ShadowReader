## A. 按钮协调化（取消深底）

规则：**深色只用在文字和描边上，任何控件的底色都不用深色。** 上一轮的深青实底 `#085049` / `#063c37` 已从所有控件底色上撤掉。`--btn-fill-active` 变量随之删除。

| 假名/译「开」、☰ 选文、× 返回 | 深青底 `#085049`，白字 | 浅薄荷底 `#e6f9f6`，薄荷描边 `#11a89b`，最深棕字 `#3b2a17`，对比 **12.58** |

几点取舍：

- **播放键为什么不用 `#3b2a17` 做字色**：`#3b2a17` 在 `#19c8b9` 上只有 6.54，不到 7。可选的做法有两种：底色换成更浅的非色板薄荷（比如 `#4fd3c6`，可到 7.50），或者字换成同系更深一档的 `#2f2112`（7.43）。我选了后者，这样底色仍是 animal 色板的薄荷主色。两种都试算过，见下表的「试算，未采用」行。
- **播放中的深青内描边为什么用 `#085049`**：先试了 `#0b6e66`，它在薄荷底上只有 2.91，达不到非文字 3:1。改用 `#085049` 后是 4.44。它只是一圈描边，不是底色，符合「深色只上描边」。
- **全部用 inset 阴影来画**：内描边和 hover 描边都是 inset 阴影，不占几何。按钮的 border 宽度没有改。
- **「开」和「关」怎么区分**：靠色相（薄荷 vs 奶油）、描边颜色和文案。两者都是浅底，不再有一黑一白的强反差。这是有意为之，目的是让页头退后。

## B. 视线聚焦跟读卡

只改了颜色、描边颜色和阴影。描边宽度、内外边距、字号都没动。

**截图脚本实测了几何**：卡片 362×384（竖屏）/ 908×628（横屏），列表 362×334 / 588×628，量测字号 `--cfs` 22px / 42px。这些都是 fit 运行时算出来的高度。由于本轮没有任何几何属性变化，排版和改前一致。

### ① 卡片提亮、立起来

- 底色：`#f7f3df` → 暖白 `#fffdf8`。这是页面上最亮的面，页底是 `#f8f8f0`。
- 描边：暖棕 `#c4b89e` → 薄荷 `#19c8b9`，宽度仍是 2px / 3px。
- 新增 4px 暖奶油 3D 底边 `#e6dabd`，和 animal 主按钮同一种语言；外加一层柔和的投影（暖棕 32% 透明度，向下 14px，模糊 30px，收缩 12px）。
- 横屏卡片获得焦点时，这层浮起的阴影保留，叠加在原有的内收黄光环上。
- 卡片上的正文对比反而都升高了：日语 10.02→10.98，译文 7.53→8.25，ruby 6.22→6.82。

### ② 周围降权

- 页头三键从「深青实底白字」改成浅薄荷底，是本轮降权幅度最大的一项。
- 「关」键和下拉的描边收浅。
- 标题、状态行、说明段的字色保持不变（7.76 / 9.17）。它们已经贴着 ≥7 的底线，没有再往浅里调的空间。降权靠的是周围不再有深色块和它们抢。
- 播放键是主操作，保留薄荷主色的存在感，但已经不是深底。

### ③ 全文列表作陪衬

- 列表底色：`#f7f3df` → `#f2eddc`，比页底略深，和卡片的暖白拉开一档。
- 列表描边收浅到 `#ddd1b4`。
- 列表里的当前句保留黄底 `#f7cd67`。左侧句条略加强：5→6px，电视上 8px，都是 inset 阴影。
- 列表正文对比因为底色变深而略有下降，但都在门槛之上：日语 9.53，译文 7.16，ruby 5.91（≥4.5），已读句 3.51（≥3）。

没有加动画，没有放大任何字号。

### 视觉层级

**第一眼落点是怎么成立的**（rev2-01 / rev2-04）：

- 卡片是全页唯一的暖白面，四周有薄荷描边，下沿有奶油 3D 底边和柔和投影，看上去从奶油页底上浮起来一层。
- 卡片里是全页最大最粗的字（字号未改），它们落在全页最亮的底上，得到最强的「亮面＋深字」反差。
- 右栏（或竖屏下方）的列表底色更暗、描边更淡，像被压进页面里一层，对比之下卡片更前。
- 页头已经没有深色块抢视线。

**被降权的元素**：

- 页头三键：深青实底 → 浅薄荷；
- 「关」键和下拉：描边收浅；
- 全文列表：底色变深一档，描边收浅；
- 标题、状态行、说明段：字色未变，但周围不再有重色，自然退后。

**肉眼结论**（逐张看过）：

| 项 | 结论 |
|---|---|
| 协调感 | 页头三键变成浅薄荷「胶囊」，和奶油底、薄荷卡片描边同一色系，不再有突兀的深块（rev2-01/04/08）。播放键是薄荷主色加 3D 底边，和 animal 风格一致，不显得重 |
| 卡片聚焦感 | 竖屏、横屏都成立。横屏左卡暖白发亮，右栏奶油偏暗，主次一眼可分（rev2-04/06）。竖屏卡片在上、列表在下，层次同样清楚（rev2-01）。列表当前句的黄底和 6/8px 深青句条仍然醒目，可以和卡片对照着跟读 |
| 控件字清晰度 | 页头键、选文键、返回键的深棕字在浅薄荷底上清楚锐利；下拉字清楚；播放键深棕字在薄荷底上清楚（rev2-04/06）；面板列表的标题和副行清楚（rev2-07/08） |
| 播放状态区分 | 播放中：深青内描边＋「暂停」（rev2-04）。暂停后：无描边＋「▶ 继续」（rev2-06）。两者可分 |
| 焦点 | 播放键聚焦是深棕外描边＋黄光环，醒目（rev2-03）。横屏卡片聚焦时，内收黄光环和深棕描边可见，浮起阴影保留（rev2-05） |

**一项取舍要说明**：横屏下播放键是第二视觉重心。它面积大、又是饱和的薄荷色，第一眼仍然先落在卡片上，但播放键的存在感明显。这是按任务书「主操作可保留主色存在感」保留的。如果希望再收一点，可以把播放键底换成中薄荷，比如 `#7fe0d6`，配 `#3b2a17` 字是 8.85。本轮没有这样做。

**截图环境问题（非 CSS）**：本机字体缺 U+23F8，播放中键上的 ⏸︎ 图标显示成方框。这是上一轮就已记录的截图环境问题，script 未改，真机一般有这个字符。
