## 硬约束

1. **功能与行为零改动**。JS 内核逻辑（HLS 会话、选文 loadArticles/selectArticle、
   跟读同步、ruby/译文三态、点句跳转、长句量测字号 fit、横竖屏布局切换、遥控
   keydown 导航与 NAV 焦点序、lastPointerNav、?s= 入口）一律原样保留。DOM 的 id、
   关键 class 钩子、v-show/tabindex 语义不得更改；为视觉加包裹层可以，但不得改变
   焦点序与元素可见性逻辑。交付时给出「v3→v4 diff 概要」证明 JS 逻辑未动
   （diff 统计＋逐段说明，样式区与结构区的改动分开列）。
2. **可读性硬指标（不达标即返工）**：
   - 正文文字（当前句卡片日语、全文日语、译文）与其底色对比度 ≥ 4.5:1（WCAG AA）。
     animal 令牌的正文棕 #725d42 在奶油底上约 5.9:1 可用；若换底色逐个核算，
     不达标就加深文字色。报告里必须附对比度核算表（前景/背景/比值/结论）。
   - 当前句高亮：高亮底＋其上文字对比 ≥ 4.5:1，且与非当前句在视觉上明确可区分；
     已读句的弱化色对比 ≥ 3:1 并在报告中说明。
   - ruby 注音：字号沿用现行规格，颜色对比尽量 ≥ 4.5:1，做不到在报告中明示实际值。
   - 焦点环：电视遥控的命脉。新主题下仍须一眼可见——现行「深色描边＋黄色光环」
     可保留或等效替换（animal 的 focus yellow #ffcc00 系），替换须在报告中说明理由。
   - 译文模糊态（blur）是功能不是装饰，保持可辨认出「有译文但被模糊」。
3. **风格落点**（按 animal 令牌，彩色但克制）：
   - 底色：奶油系 --animal-bg #f8f8f0 / 内容区 rgb(247,243,223)；**正文卡片与全文区
     底色保持纯净平整**，波点/彩色针糖等装饰只许出现在页头、页边、空白区。
   - 文字：暖棕系，绝不用纯黑；标题可更深更粗（600–900）。
   - 主色：薄荷绿 --animal-primary #19c8b9 只作点缀与强调。注意 #19c8b9 配白字对比
     不足——主按钮（播放键）的文字/图标色与底色组合必须核算达标（可用深棕字、
     或加深主色作底＋白字，给出核算值）。
   - 形状：卡片圆角 18–24px，按钮/开关 pill 化（50px），交互元素圆角不小于 12px；
     主按钮带 animal 标志性的 3D 堆叠阴影（box-shadow 底边式），次要按钮扁平。
   - 字体：沿用本页现有自托管字体链；可在链首加 Nunito（仅名字，不新增网络请求，
     无此字体时自然回退）与圆体，**不得新增任何外部字体/资源请求**（电视 webOS 需
     离线可用）；正文字重不低于 500 的观感（现行规格优先，不为风格改字号体系）。
   - 动效：过渡统一 cubic-bezier(0.4, 0, 0.2, 1)、0.15–0.35s；不加持续性动画
     （跟读页要安静，当前句切换的既有过渡保留）。
   - 整体替换现行蓝色系变量（--brand #1f5a99 等），选文面板、假名/译开关、
     语言/语速下拉、选文列表项、状态行、audio 元素都要纳入新主题，不留旧色残片
     （焦点环的黄、译文模糊等功能色除外，按第 2 条处理）。
4. **形态不变**：仍是单文件 HTML＋现有本地 vue.global.prod.js / hls.min.js 引用；
   不引入 React、不引入 animal-island-ui 包、不加构建步骤、不加 CDN。
